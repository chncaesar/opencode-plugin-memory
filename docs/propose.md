Work in your project as usual. When you encounter a lesson that would help another session, you can ask:

> Remember that reports must identify inventory records by both product and batch.

The agent may also propose durable knowledge without an explicit request, for example after discovering a project convention or receiving a correction about how to work. A good memory captures an actionable lesson, not a transcript of one task.

The agent proposes the memory and opens its pull request in the same workflow: while a proposal is still waiting, the plugin reminds the agent that it has no pull request yet. You do not need to ask it to publish or confirm a separate publishing step. **The memory is not active yet**: inspect it in the pull request, then merge it if it is correct.

Prefer project instructions for mandatory, explicitly maintained rules. Avoid storing secrets, one-off task details, or facts that are already documented and easy to look up. [What should become a memory?]({% link rule-becomes-feature.md %}) gives practical examples.
