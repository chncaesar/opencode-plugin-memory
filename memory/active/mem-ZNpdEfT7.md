向 r/opencode 发布插件/工具帖时，真正会杀掉帖子的不是版主，而是 Reddit 的站级垃圾过滤器（`removed_by_category: reddit`，不是 `moderator`，也不是 `automod_filtered`）。实测 400 条近期帖中移除率 12.75%，**51 条移除全部来自系统过滤器，版主移除为 0**；这个区几乎没有成文版规，也没有强制分类标签。

**关键实测结论：换标题、换体裁都无效。** 同一账号连续两次发同一插件的推广帖——第一次是长标题链接帖，第二次换成更短的标题和文字帖——**两次都被过滤器直接删除**。所以不要指望"改文案就能过"，过滤器判定的是账号 + 推广特征 + 外链，不是措辞。

**因此第一次被删之后就不要再试。** 不是"隔一天换标题再发一次"，而是直接停手。连续提交被过滤器判死的推广内容，是账号级标记的典型触发路径。

**补救手段只有一个**：给版主发一次消息请求人工放行被过滤的帖子（侧栏有 message the mods）。只发一次，不要催。

**判定是否全站封禁**：查该账号在其它 subreddit 的历史帖子——若久远的非推广帖仍正常显示，说明不是全站 shadowban，只是推广类内容被持续拦截；这种情况下继续在别的小区发同类推广，同样会被拦。

**长期解法**：先在该区正常参与几周攒权重，再发，且不带外链；或者干脆换平台。插件帖在该区中位数仅 2 分，投入产出本就不高。
