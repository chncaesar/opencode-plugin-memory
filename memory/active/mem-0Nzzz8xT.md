向 r/opencode 发布插件/工具帖时，真正会杀掉帖子的不是版主，而是 Reddit 的站级垃圾过滤器。实测 400 条近期帖中移除率 12.75%，**51 条移除全部标记为 `reddit`，版主移除数量为 0**；这个区实际上没有成文版规（版主唯一的公开表态是"和 OpenCode 相关的都可以发"），也没有强制分类标签（400 条帖全部无标签）。

**因此被过滤后不要用同一标题重发**——同一账号重复提交已被过滤器判死的标题，是账号级标记的典型触发模式。正确做法是换标题、换开头、换成文字帖，并间隔一段时间。

**能在该区存活的帖文形态**（从实测数据反推）：
- 文字帖优先，不要用链接帖直接把 URL 丢出去；链接放在正文末尾。
- 标题里不要出现 GitHub 地址——高分插件帖无一例在标题中放链接。
- 标题 40–60 字符，插件名 + 一句差异化，例如"名字 + 机制/收益"；带括注说明用途的也能活。
- 正文要给**具体的前后对比数字**（实例："10 个会话从 894MB 降到 3MB"），这是唯一能突破插件帖中位数 2 分的做法。
- 别用"promoting again"、"求测试求反馈"这类纯索取的开口——实测 0 分。

**预期管理**：插件帖中位数 2 分，6–11 分属于正常偏好，能到 60+ 的是带演示图的个例；该区最高分帖全是截图和模型新闻，不是工具发布。另有一个 5.7 万人的 r/opencodeCLI 与之受众重叠，可作为备选。

**账号门槛未证实**：有第三方称需 25 karma + 注册满 7 天，但无法从官方途径核实；新账号发推广内容是高风险组合。
